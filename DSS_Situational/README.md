# СППР на основе ситуационного подхода

**Система поддержки принятия решений** (СППР) реализует ситуационный (прецедентный) подход:
система сравнивает текущую ситуацию с эталонными прецедентами в базе знаний и выдаёт
ранжированный список рекомендованных решений.

## Архитектура

```
DSS_Situational/
├── Models/
│   ├── Situation.cs            # Ситуация — набор параметров-признаков
│   ├── SituationParameter.cs   # Один параметр (имя, значение, вес, ед.изм.)
│   ├── Decision.cs             # Решение с описанием и списком действий
│   ├── KnowledgeBaseEntry.cs   # Запись БЗ: эталонная ситуация + решение
│   └── RecognitionResult.cs    # Результат сопоставления (сходство, решение)
│
├── Services/
│   ├── SituationMatcher.cs     # Алгоритм сходства (взвешенное евклидово расстояние)
│   ├── KnowledgeBaseService.cs # CRUD + JSON-персистентность базы знаний
│   └── DecisionEngine.cs       # Движок анализа (оркестрирует Matcher и KB)
│
├── ViewModels/
│   ├── MainViewModel.cs        # ViewModel главного окна
│   ├── KnowledgeBaseViewModel.cs
│   └── ParameterRowViewModel.cs
│
├── Views/
│   ├── MainWindow.xaml         # Главное окно: ввод ситуации + результаты
│   ├── KnowledgeBaseWindow.xaml# Просмотр и управление базой знаний
│   └── LearnDialog.xaml        # Диалог добавления нового прецедента
│
└── Data/
    └── knowledge_base.json     # База знаний (7 прецедентов из двух доменов)
```

## Алгоритм распознавания ситуации

1. Пользователь вводит значения параметров текущей ситуации и их веса.
2. `DecisionEngine.Analyze()` передаёт ситуацию в `SituationMatcher`.
3. `SituationMatcher` вычисляет **взвешенное нормализованное евклидово расстояние**
   между текущими и эталонными параметрами, преобразуя его в коэффициент сходства [0..1].
4. Результаты фильтруются по порогу (по умолчанию 30%) и сортируются по убыванию сходства.
5. Отображается рекомендованное решение с конкретными действиями.

## Требования

- .NET 8 SDK
- Windows 10/11 (WPF)
- Visual Studio 2022 или `dotnet build`

## Сборка и запуск

```bash
cd DSS_Situational
dotnet build
dotnet run
```

## Предустановленная база знаний

| Домен                    | Ситуации                                              |
|--------------------------|-------------------------------------------------------|
| Диагностика оборудования | Перегрев, дисбаланс, утечка давления, перегрузка, норма |
| Производственный процесс | Брак продукции, низкая производительность             |
