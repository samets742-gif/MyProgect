## [1.0.0] — 2026-03-15

### Добавлено

#### Ядро системы (общее для всех версий)
- Доменные модели: `Situation`, `SituationParameter`, `Decision`, `KnowledgeBaseEntry`, `RecognitionResult`
- `SituationMatcher` — алгоритм взвешенного нормализованного евклидова расстояния (CBR)
  - Калибровка диапазонов нормализации по всей базе знаний
  - Корректная обработка нулевого диапазона (нормализация по максимальному значению)
  - Сравнение только по общим параметрам (отсутствующие игнорируются)
- `KnowledgeBaseService` — CRUD-операции с JSON-персистентностью
- `DecisionEngine` — оркестратор анализа: фильтрация, калибровка, сортировка, статистика

#### Начальная база знаний (7 прецедентов)
- **Диагностика оборудования:** перегрев подшипника, дисбаланс ротора, утечка давления, перегрузка двигателя, нормальная работа
- **Производственный процесс:** брак продукции, низкая производительность

#### DSS_Blazor — Web / Mobile (Blazor WebAssembly)
- SPA-приложение, работает в любом браузере без установки
- Мобильная адаптация: нижняя навигация, отзывчивый дизайн
- Хранение базы знаний в `localStorage` браузера
- Инлайн-диалог обучения на странице анализа
- Страница управления базой знаний с полным CRUD
- SPA-роутинг на GitHub Pages через `404.html`
- Публикация на GitHub Pages: `https://samets742-gif.github.io/Dss/`

#### DSS_Avalonia — Кроссплатформенный десктоп
- Поддержка Linux, Windows, macOS
- MVVM-архитектура с `IDialogService` для декаплинга
- `AsyncRelayCommand` для асинхронных операций
- Кастомные диалоги: `ConfirmDialog`, `LearnDialog`
- Хранение данных в `knowledge_base.json` рядом с исполняемым файлом

#### DSS_Situational — Windows WPF
- MVVM-архитектура
- Три окна: главный анализ, база знаний, диалог обучения
- DataGrid для просмотра и редактирования базы знаний

#### CI/CD
- GitHub Actions: автоматическая публикация Blazor на GitHub Pages при push в main
- GitHub Actions: сборка всех трёх проектов (CI)

#### Документация
- `docs/README_DSS.md` — полное описание проекта с примерами
- `docs/architecture.md` — архитектурная документация с диаграммами

- `docs/user-guide.md` — руководство пользователя
- `CHANGELOG.md` — история изменений
- `LICENSE` — MIT лицензия
