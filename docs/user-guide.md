## Анализ ситуации

### Шаг 1 — Введите название ситуации

В поле «Название ситуации» введите краткое описание того, что происходит.
Пример: `Шум в подшипнике правого двигателя`

### Шаг 2 — Добавьте параметры

Нажмите **«+ Добавить параметр»** и заполните три поля:

| Поле | Описание | Пример |
|------|----------|--------|
| Имя параметра | Название измеряемой величины | `Температура` |
| Значение | Числовое значение | `92` |
| Вес (0–1) | Важность параметра при сравнении | `1.0` |

**Рекомендации по весам:**
- `1.0` — параметр критически важен
- `0.7–0.9` — параметр важен
- `0.3–0.6` — вспомогательный параметр
- `0.0` — параметр игнорируется

Добавьте столько параметров, сколько нужно для описания ситуации.

### Шаг 3 — Запустите анализ

Нажмите кнопку **«Анализировать»**.

Система сравнит текущую ситуацию с каждой записью в базе знаний и выдаст список наиболее похожих прецедентов.

## Работа с базой знаний

Перейдите на страницу **«База знаний»** (нижняя навигация или кнопка в меню).

### Просмотр записей

В таблице отображаются все прецеденты:
- **Категория** — домен знаний
- **Название** — имя эталонной ситуации
- **Решение** — рекомендованное действие
- **Использований** — счётчик применений
- **Последнее использование** — дата

### Добавление новой записи

1. Нажмите **«+ Добавить запись»**
2. Укажите категорию (или создайте новую)
3. Введите название эталонной ситуации
4. Добавьте параметры с типичными значениями для этой ситуации
5. Укажите решение: заголовок, описание, приоритет (1 = высший) и список действий
6. Нажмите **«Сохранить»**

### Редактирование записи

Нажмите **«Изменить»** рядом с нужной записью.

### Удаление записи

Нажмите **«Удалить»** и подтвердите действие.

### Сброс к начальному состоянию

Кнопка **«Сбросить базу»** восстанавливает 7 предустановленных прецедентов.
⚠️ Все добавленные вами записи будут удалены.

## Обучение системы

После анализа ситуации вы можете добавить текущий случай в базу знаний:

1. Выполните анализ
2. Нажмите **«Сохранить в базу знаний»** (кнопка появляется под результатами)
3. В открывшемся диалоге:
   - Укажите категорию
   - Введите или подтвердите название ситуации
   - Заполните решение (что нужно сделать)
4. Нажмите **«Сохранить»**

Система запомнит прецедент и будет использовать его при последующих анализах.

## Интерпретация результатов

Каждый найденный прецедент показывается с коэффициентом сходства:

| Сходство | Значение | Действие |
|----------|----------|----------|
| **≥ 90%** | Высокий | Следовать решению |
| **70–89%** | Средний | Следовать с проверкой |
| **50–69%** | Низкий | Использовать как подсказку |
| **< 50%** | Очень низкий | Требуется эксперт |

Если результатов нет — ни один прецедент не превысил порог сходства (30% по умолчанию). Добавьте больше параметров или обогатите базу знаний.

## Советы и подсказки

### Качество анализа

- **Больше параметров** = точнее сравнение. Добавляйте все доступные показатели.
- **Согласованность имён** критична: `Температура` и `температура` — разные параметры. Используйте одинаковое написание во всех записях.
- **Расширяйте базу знаний** реальными случаями: чем больше прецедентов, тем точнее система.

### Категории

Используйте категории для организации прецедентов по доменам:
- `Диагностика оборудования`
- `Производственный процесс`
- `Медицина`

При анализе можно (необязательно) фильтровать поиск по категории — это ускоряет работу при большой базе.

### Хранение данных

**Web-версия:** данные хранятся в `localStorage` вашего браузера.
Это значит:
- При очистке данных браузера база знаний сбросится
- В режиме инкогнито изменения не сохраняются после закрытия вкладки
- На разных устройствах базы знаний независимы

**Десктоп-версии:** данные хранятся в файле `knowledge_base.json` рядом с исполняемым файлом.

### Экспорт и перенос данных

Для переноса базы знаний между устройствами:
1. Откройте DevTools браузера (F12)
2. Перейдите в Application → Local Storage
3. Скопируйте значение ключа `dss_knowledge_base`
4. На новом устройстве вставьте это значение в тот же ключ

## Начальная база знаний

Система поставляется с 7 предустановленными прецедентами:

### Диагностика оборудования

| Ситуация | Параметры | Решение |
|----------|-----------|---------|
| Перегрев подшипника | Температура 95°C, Вибрация 8.5 мм/с | Аварийная остановка, замена подшипника |
| Дисбаланс ротора | Вибрация 15 мм/с, Температура 65°C | Балансировка ротора |
| Утечка давления | Давление 1.5 бар, Температура 55°C | Поиск и устранение утечки |
| Перегрузка двигателя | Ток 45 А, Температура 88°C | Снижение нагрузки |
| Нормальная работа | Температура 45°C, Вибрация 2.0 мм/с | Продолжить работу |

### Производственный процесс

| Ситуация | Параметры | Решение |
|----------|-----------|---------|
| Брак продукции | Отклонение размера 2.5 мм, Температура 78°C | Настройка оборудования |
| Низкая производительность | Скорость 60%, Время цикла 45 с | Оптимизация процесса |
