# Алгоритм распознавания ситуаций

## Теоретическая основа

Система реализует **метод ближайшего прецедента** (Case-Based Reasoning, CBR) с использованием **взвешенного нормализованного евклидова расстояния** в пространстве признаков ситуации.

---

## Формализация задачи

**Вход:**
- Текущая ситуация `S = {(n₁, v₁, w₁), ..., (nₖ, vₖ, wₖ)}`
  - `nᵢ` — имя параметра
  - `vᵢ` — числовое значение
  - `wᵢ` — вес параметра `wᵢ ∈ [0, 1]`
- База знаний `KB = {(Sⱼ, Dⱼ)}` — множество пар (ситуация, решение)

**Выход:**
- Список `R = {(Sⱼ, Dⱼ, simⱼ)}`, отсортированный по `simⱼ` по убыванию

---

## Шаги алгоритма

### 1. Фильтрация базы знаний (опционально)

Если задан фильтр по категории `C`:
```
KB_filtered = {(Sⱼ, Dⱼ) ∈ KB : category(Sⱼ) = C}
```

### 2. Калибровка диапазонов (нормализация)

Для каждого параметра `n` находим диапазон значений по всей базе:
```
range_min[n] = min { v : (n, v, w) ∈ Sⱼ, Sⱼ ∈ KB_filtered }
range_max[n] = max { v : (n, v, w) ∈ Sⱼ, Sⱼ ∈ KB_filtered }
range[n] = range_max[n] − range_min[n]
```

### 3. Вычисление сходства

Для каждой записи `(Sⱼ, Dⱼ) ∈ KB_filtered`:

**Определяем общие параметры:**
```
Common(S, Sⱼ) = { nᵢ : nᵢ ∈ params(S) ∧ nᵢ ∈ params(Sⱼ) }
```

**Нормализованная разность по параметру `n`:**
```
         │ vˢ[n] − vˢʲ[n] │
δ[n] = ──────────────────────   если range[n] > 0
              range[n]

         │ vˢ[n] − vˢʲ[n] │
δ[n] = ──────────────────────   иначе (относительно max)
          max(│vˢ[n]│, │vˢʲ[n]│)
```

**Взвешенное расстояние:**
```
        ┌    Σ        wᵢ · δ[nᵢ]²  ┐
dist = √│ ─────────────────────────  │
        └    Σ        wᵢ             ┘
          nᵢ ∈ Common(S, Sⱼ)
```

**Коэффициент сходства:**
```
sim(S, Sⱼ) = max(0, 1 − dist)
```

### 4. Фильтрация и ранжирование

```
R = { (Sⱼ, Dⱼ, simⱼ) : simⱼ ≥ threshold }
R_sorted = sort(R, by=sim, order=DESC)
R_result = R_sorted[:max_results]
```

## Интерпретация результатов

| Сходство | Уровень уверенности | Рекомендация |
|----------|---------------------|-------------|
| ≥ 90% | Высокий | Следовать решению |
| 70–89% | Средний | Следовать с проверкой |
| 50–69% | Низкий | Использовать как подсказку |
| < 50% | Очень низкий | Требуется эксперт |

## Пример вычисления

**Текущая ситуация:**
| Параметр | Значение | Вес |
|----------|----------|-----|
| Температура | 92°C | 1.0 |
| Давление | 3.4 бар | 0.7 |
| Вибрация | 9.0 мм/с | 0.9 |

**Эталон «Перегрев подшипника»:**
| Параметр | Значение | Диапазон в БЗ |
|----------|----------|--------------|
| Температура | 95°C | [20, 95] → range=75 |
| Давление | 3.5 бар | [1.2, 4.8] → range=3.6 |
| Вибрация | 8.5 мм/с | [3.0, 18.0] → range=15 |

**Расчёт:**
```
δ[Температура] = |92 - 95| / 75 = 0.04
δ[Давление]    = |3.4 - 3.5| / 3.6 = 0.028
δ[Вибрация]    = |9.0 - 8.5| / 15 = 0.033

dist = √( (1.0 × 0.04² + 0.7 × 0.028² + 0.9 × 0.033²) / (1.0 + 0.7 + 0.9) )
     = √( (0.0016 + 0.000549 + 0.000980) / 2.6 )
     = √( 0.003129 / 2.6 )
     = √0.001203 ≈ 0.0347

sim = 1 − 0.0347 ≈ 0.965 → 96.5% (Высокий уровень уверенности)
```

## Параметры настройки

| Параметр | По умолчанию | Описание |
|----------|-------------|---------|
| `SimilarityThreshold` | 0.3 | Минимальный порог сходства |
| `MaxResults` | 5 | Максимальное число рекомендаций |
| `CategoryFilter` | null | Фильтр по домену знаний |
| `Weight` каждого параметра | 1.0 | Важность признака при сравнении |

---

## Особенности реализации

- **Отсутствующие параметры:** если в эталоне нет параметра из текущей ситуации — он игнорируется (сравниваются только общие)
- **Нулевой диапазон:** если все значения параметра в БЗ одинаковы — нормализация по максимальному значению
- **Пустая база:** возвращается пустой список без ошибки
- **Вес 0:** параметр не влияет на результат (но участвует в сумме весов знаменателя, поэтому фактически исключается автоматически через числитель)
