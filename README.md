# Справочно‑информационная система учета приборов и деталей

Проект: WPF + C# + MS SQL Server + ADO.NET. Интерфейс на русском языке.

## Назначение
Приложение для учета приборов (сборок) и деталей, управления спецификациями, чертежами и 3D‑моделями Siemens NX, а также экспорта/импорта данных.

## Технологии
- C# / .NET 6
- WPF (MVVM)
- MS SQL Server
- ADO.NET
- OpenXML (Word/Excel)

## Установка и запуск
1. Убедитесь, что установлен .NET SDK 6.
2. Убедитесь, что доступен SQL Server `localhost\SQLEXPRESS`.
3. Выполните скрипт БД: `Sql/CADDevicesDb.sql` (или через приложение, если БД уже создана).
4. Сборка:
   ```
   dotnet build
   ```
5. Запуск:
   ```
   dotnet run
   ```

## Структура БД
Основные таблицы:
- `Devices` — приборы
- `Parts` — детали
- `Spec_*` — таблицы параметров для стандартных типов
- `CustomPartTypes`, `CustomPartParams`, `CustomPartValues` — пользовательские типы деталей

## Основной функционал
- CRUD приборов
- CRUD деталей выбранного прибора
- Параметры деталей по таблицам `Spec_*`
- Пользовательские типы деталей с параметрами (Text/Number/Date/List)
- Хранение чертежей в БД (VARBINARY)
- Хранение путей к NX‑моделям (строка) + открытие по ассоциации
- Экспорт: Word / Excel / XML
- Импорт: Word / Excel / XML (формат экспортных файлов)
- Печать чертежей сборки и деталей

## Пользовательские типы деталей
1. Откройте «Пользовательские типы» в панели «Детали прибора» (вкладка «Действия»).
2. Создайте тип.
3. Добавьте параметры (тип: Text / Number / Date / List).
   - Для List укажите значения через `;`.
4. При добавлении детали выберите созданный тип и заполните параметры.

## Экспорт
- Прибор: экспортирует весь прибор со всеми деталями.
- Детали: экспортирует только выбранные детали.

Word:
- Для прибора добавляется чертеж сборки.
- Для экспорта выбранных деталей чертеж сборки не добавляется, только чертежи выбранных деталей.

## Импорт
Импорт поддерживает только файлы, созданные экспортом приложения.
- Word/Excel/Xml → создается прибор и/или детали.
- Изображения чертежей не импортируются (только параметры).

## Черчежи и 3D‑модели
- Чертежи хранятся в БД (VARBINARY).
- 3D‑модель хранится как путь к файлу NX.
- Открытие через `Process.Start` по ассоциации Windows.

## Печать
Кнопки печати доступны во вкладках «Действия»:
- «Печать чертежа сборки»
- «Печать чертежа детали»

## Примечания
- Если NX не установлен или не настроена ассоциация файлов, 3D‑модель может не открываться.
- Для импорта Word/Excel/XML используйте файлы, созданные экспортом приложения.

## Файлы и каталоги
- `Models/` — DTO
- `Data/` — репозитории ADO.NET
- `ViewModels/` — MVVM
- `Views/` — окна WPF
- `Services/` — сервисы (экспорт/импорт, NX, изображения)
- `Sql/` — DDL и миграции
